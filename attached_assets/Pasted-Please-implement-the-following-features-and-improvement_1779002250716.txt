## 🔴 PRIORITY 1 — Reports & Analytics Dashboard

Add a dedicated Reports & Analytics page accessible to admin and super_admin roles.

**Ticket Analytics:**
- Total tickets by status (opened / pending / solved) as cards with counts
- Average resolution time per technician and per category
- SLA compliance rate: percentage of tickets solved within the due date
- Top 5 most frequent ticket categories (bar chart)
- Tickets created per day/week/month (line chart)
- Tickets by priority breakdown (pie or donut chart)

**Team Performance:**
- Per-technician table: assigned tickets, solved tickets, average resolution time, satisfaction rating average
- Leaderboard sorted by solved tickets

**Asset Analytics:**
- Assets by type breakdown
- Assets by condition (good / fair / poor)
- Assets with warranty expiring in the next 30 / 60 / 90 days (count cards + list)

**Attendance Analytics:**
- Late arrivals count per employee this month
- Remote vs office attendance ratio
- Average working hours per employee

Use Recharts or Chart.js for all charts. Add date range filter (this week / this month / last 3 months / custom range) at the top of the page that applies to all charts.

## 🔴 PRIORITY 2 — Export to Excel and PDF

Add export buttons throughout the system:

- **Tickets page**: Export filtered tickets list to Excel (.xlsx) — columns: ID, title, category, priority, status, assigned to, created by, created date, solved date, resolution time
- **Attendance page**: Export monthly attendance report to Excel — columns: employee name, date, login time, logout time, hours worked, attendance type, late (yes/no)
- **Assets page**: Export full assets list to Excel — columns: name, type, brand, model, serial number, status, condition, assigned to, purchase date, warranty expires
- **Penalties page**: Export penalties to Excel
- **Reports page**: Export any chart data to Excel, and add a "Print / Export PDF" button that generates a formatted PDF of the entire reports page

Use `xlsx` (SheetJS) library for Excel export and `jspdf` + `html2canvas` for PDF export. Add export buttons with a download icon next to page titles.

## 🟢 PRIORITY 10 — Onboarding / Offboarding Checklist

**New database table `onboarding_tasks`:**
- id, user_id, task_name, task_type (onboarding/offboarding), completed, completed_by, completed_at, due_date, created_at

**Features:**
- When admin creates a new employee, automatically generate a default onboarding checklist: Create email account, Assign laptop/device, Set up system access, Create necessary accounts (add accounts listed in settings), Give office tour, Complete HR paperwork

- Show onboarding progress bar on the employee profile page
- Default checklist items should be configurable in Settings

## ⚙️ GENERAL IMPROVEMENTS

1. **Multiple attachments per ticket reply**: Allow uploading up to 5 files/images per reply (currently limited to 1). Show thumbnail previews before sending.

2. **Ticket sub-categories**: Add a `subcategory` field to tickets. When a category is selected, show a dependent dropdown of subcategories. Subcategory list should be configurable in Settings.

3. **Full audit log page**: Add an Audit Log page (super_admin only) that shows every significant action in the system: logins, ticket status changes, asset assignments, settings changes, user creation/deletion. Store in a new `audit_logs` table with: user_id, action_type, entity_type, entity_id, description, ip_address, created_at.

4. **Improved mobile PWA**: Ensure all pages are fully responsive and usable on mobile. The attendance check-in button should be prominent and accessible without scrolling on mobile. Add a bottom navigation bar for mobile users with: Home, Tickets, Assets, Profile.

5. **Ticket merge**: Allow admin to merge duplicate tickets (select a primary ticket, all replies and history from the duplicate move to the primary, duplicate is marked as "merged" and closed).

6. **Satisfaction rating reports**: The rating system exists but is not surfaced in reports. Add to the Reports page: average satisfaction score per technician, rating distribution chart, and recent low ratings list (1-2 stars) for quick follow-up.
