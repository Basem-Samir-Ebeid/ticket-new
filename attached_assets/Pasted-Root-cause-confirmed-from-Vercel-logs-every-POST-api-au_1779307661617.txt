Root cause confirmed from Vercel logs: every `POST /api/auth/login` returns 500.

The bug is in `api/index.js` line 76:
```js
const rows = await sql(text, params)  // ← WRONG
return { rows }
```

`neon()` from `@neondatabase/serverless` returns a **tagged template literal function**, not a regular function. Calling it as `sql(text, params)` does NOT return `{ rows: [...] }` — it returns a raw array (the result itself), so `{ rows }` becomes `{ rows: [array] }` which breaks everything downstream.
