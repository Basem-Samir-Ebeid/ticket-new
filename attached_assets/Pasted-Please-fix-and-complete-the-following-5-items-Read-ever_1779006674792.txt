## 1 — Multiple Attachments: Fix display in reply thread

The upload already works (multiple files sent as `attachments` array). The problem is in the reply thread rendering — it only shows `r.image_url` via the old `FileAttachment` component and ignores the `attachments` array entirely.

**Fix the reply rendering in AdminDashboard, EmployeeDashboard, and MemberDashboard:**

Replace the single `<FileAttachment url={r.image_url} name={r.attachment_name} />` with logic that handles both old single-file replies and new multi-file replies:

```jsx
{/* Show new multi-file attachments array */}
{r.attachments?.length > 0 && (
  <div className="flex flex-wrap gap-2 mt-2">
    {r.attachments.map((url, i) => {
      const isImage = /\.(jpg|jpeg|png|gif|webp|svg)$/i.test(url)
      return isImage ? (
        <img
          key={i}
          src={url}
          alt={`attachment-${i}`}
          className="max-w-[180px] max-h-[180px] rounded-lg object-cover cursor-pointer border border-white/10"
          onClick={() => window.open(url, '_blank')}
        />
      ) : (
        <a
          key={i}
          href={url}
          target="_blank"
          rel="noopener noreferrer"
          className="flex items-center gap-1.5 text-xs text-indigo-400 hover:text-indigo-300 bg-white/5 border border-white/10 rounded-lg px-3 py-1.5"
        >
          📎 {url.split('/').pop()}
        </a>
      )
    })}
  </div>
)}
{/* Fallback: show old single-file attachment for backward compatibility */}
{(!r.attachments?.length) && <FileAttachment url={r.image_url} name={r.attachment_name} />}
```

Apply this fix in the reply thread in: `AdminDashboard.jsx`, `EmployeeDashboard.jsx`, and `MemberDashboard.jsx`.

## 2 — Thumbnail Preview before sending (reply form)

Currently the reply form only shows a plain text counter like "3 file(s)" with no visual preview. Replace this with proper per-file previews:

**In the reply form (all three dashboards), replace the current file count display with:**

```jsx
{replyFiles.length > 0 && (
  <div className="flex flex-wrap gap-2 mt-2">
    {replyFiles.map((file, i) => {
      const isImage = file.type.startsWith('image/')
      const previewUrl = isImage ? URL.createObjectURL(file) : null
      return (
        <div key={i} className="relative group">
          {isImage ? (
            <img
              src={previewUrl}
              alt={file.name}
              className="w-16 h-16 object-cover rounded-lg border border-white/10"
            />
          ) : (
            <div className="w-16 h-16 flex flex-col items-center justify-center rounded-lg border border-white/10 bg-white/5 text-center px-1">
              <span className="text-lg">📎</span>
              <span className="text-[9px] text-slate-400 truncate w-full text-center mt-0.5">
                {file.name.split('.').pop().toUpperCase()}
              </span>
            </div>
          )}
          {/* file size */}
          <span className="absolute bottom-0 left-0 right-0 text-[8px] text-center text-slate-400 bg-black/50 rounded-b-lg py-0.5">
            {(file.size / 1024).toFixed(0)}KB
          </span>
          {/* remove button */}
          <button
            type="button"
            onClick={() => setReplyFiles(prev => prev.filter((_, j) => j !== i))}
            className="absolute -top-1.5 -right-1.5 w-4 h-4 rounded-full bg-red-500 text-white text-[10px] flex items-center justify-center opacity-0 group-hover:opacity-100 transition-opacity"
          >
            ×
          </button>
        </div>
      )
    })}
  </div>
)}
```

Make sure to revoke object URLs on cleanup to avoid memory leaks:
```js
useEffect(() => {
  return () => replyFiles.forEach(f => {
    if (f.type.startsWith('image/')) URL.revokeObjectURL(URL.createObjectURL(f))
  })
}, [replyFiles])
```

Apply this in `AdminDashboard.jsx`, `EmployeeDashboard.jsx`, and `MemberDashboard.jsx`.
