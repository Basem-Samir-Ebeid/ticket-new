Please apply the following fixes across 5 files. The root cause is that `toISOString()` returns UTC dates, but Egypt is UTC+3, so date comparisons fail. All date functions must use `Africa/Cairo` timezone.

---

## Fix 1 — `server/routes/factory-rotation.ts`

Find:
```ts
function toDateStr(date: Date): string {
  return date.toISOString().slice(0, 10)
}
```
Replace with:
```ts
function toDateStr(date: Date): string {
  return date.toLocaleDateString('en-CA', { timeZone: 'Africa/Cairo' })
}
```

Also find:
```ts
    const rowDateStr = typeof row.scheduled_date === 'string'
      ? row.scheduled_date.slice(0, 10)
      : new Date(row.scheduled_date as any).toISOString().slice(0, 10)
```
Replace with:
```ts
    const rowDateStr = typeof row.scheduled_date === 'string'
      ? row.scheduled_date.slice(0, 10)
      : new Date(row.scheduled_date as any).toLocaleDateString('en-CA', { timeZone: 'Africa/Cairo' })
```

      .select()
