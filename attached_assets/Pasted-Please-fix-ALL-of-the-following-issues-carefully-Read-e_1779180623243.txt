## FIX 3 — Restrict CORS to known origins

**File: `server/app.ts`**

Replace:
```ts

```
With:
```ts
const allowedOrigins = [
  process.env.FRONTEND_URL,
  'http://localhost:5000',
].filter(Boolean)

app.use(cors({
  origin: (origin, callback) => {
    if (!origin || allowedOrigins.includes(origin)) return callback(null, true)
    callback(new Error('Not allowed by CORS'))
  },
  credentials: true,
}))
```

Add `FRONTEND_URL` to Replit Secrets with the production Vercel URL (e.g. `https://your-app.vercel.app`).

## FIX 6 — Wrap leave approval in a DB transaction

**File: `server/routes/leaves.ts`** — the `PATCH /:id/approve` endpoint

The current code updates `leaveRequests` and then `profiles` as two separate queries. If the second fails, the leave is approved but balance is not deducted.

Wrap both updates in a transaction:
```ts
await db.transaction(async (tx) => {
  await tx.update(leaveRequests).set({ status: 'approved', ... }).where(eq(leaveRequests.id, req.params.id))
  // balance deduction update here using tx.update(profiles)...
})
```

Do the same for `PATCH /:id/reject` where balance is restored.

## FIX 8 — Create Singleton Resend client

**File: `server/email.ts`**

Replace the current function (which creates a new Resend instance on every call) with:
```ts
import { Resend } from 'resend'

const resendClient = process.env.RESEND_API_KEY ? new Resend(process.env.RESEND_API_KEY) : null

export async function sendEmail(to: string, subject: string, html: string) {
  if (!resendClient) return
  try {
    await resendClient.emails.send({
      from: process.env.RESEND_FROM_EMAIL || 'onboarding@resend.dev',
      to,
      subject,
      html,
    })
  } catch (err) {
    console.error('Email send error:', err)
  }
}
```
