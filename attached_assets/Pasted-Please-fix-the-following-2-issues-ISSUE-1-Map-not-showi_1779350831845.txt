ISSUE 1 — Map not showing on the Office Location settings page

The map container renders as a black/empty box. This is likely because 
Leaflet's CSS is not loading properly on Vercel, or the map is initializing 
before the DOM element is ready.

Fix in the component that renders the office map (DraggableOfficeMap.jsx 
or similar):

1. Make sure Leaflet CSS is imported at the top of the file:
   import 'leaflet/dist/leaflet.css'

2. Wrap the map initialization in a useEffect with a small delay to ensure 
   the container div is mounted:
   useEffect(() => {
     const timer = setTimeout(() => {
       // initialize map here
     }, 100)
     return () => clearTimeout(timer)
   }, [])

3. Make sure the map container div has an explicit height:
   <div id="map" style={{ width: '100%', height: '400px' }}></div>
   (without explicit height, Leaflet renders invisible)

4. Also fix the Leaflet default marker icon broken issue on Vite/Vercel 
   by adding this at the top of the map component:
   import L from 'leaflet'
   delete L.Icon.Default.prototype._getIconUrl
   L.Icon.Default.mergeOptions({
     iconRetinaUrl: 'https://unpkg.com/leaflet@1.9.4/dist/images/marker-icon-2x.png',
     iconUrl: 'https://unpkg.com/leaflet@1.9.4/dist/images/marker-icon.png',
     shadowUrl: 'https://unpkg.com/leaflet@1.9.4/dist/images/marker-shadow.png',
   })

ISSUE 2 — Allow employees to clock out (logout attendance) from anywhere, 
regardless of their distance from the office

Currently the checkout/logout attendance route checks if the employee is 
within the office radius before allowing them to clock out. This restriction 
should be removed for logout only — employees should be able to clock out 
from any location.

Find the attendance logout/checkout route in api/index.js and 
server/routes/attendance.ts. Look for the distance/radius check on logout 
and remove it. The check should only apply to clock-in (login), not clock-out.

The fix should look something like this — remove or skip the radius check 
when action is 'logout' or 'checkout':

// Only enforce location check for clock-IN, not clock-OUT
if (action === 'login' || action === 'checkin') {
  const distance = calcDistance(lat, lng, officeLat, officeLng)
  if (distance > officeRadius) {
    return res.status(403).json({ 
      error: 'أنت خارج نطاق المكتب. لا يمكن تسجيل الحضور.' 
    })
  }
}
// Clock-out is always allowed regardless of location

Apply this fix in both api/index.js and server/routes/attendance.ts
