## Add Email Notifications using Resend

Please integrate email notifications into the project using the Resend service. I will provide the API key separately as an environment variable `RESEND_API_KEY`.

---

### STEP 1 — Install & Setup

```bash
npm install resend
```

Create a new file `server/email.ts`:

```ts
import { Resend } from 'resend'

const resend = new Resend(process.env.RESEND_API_KEY)

export async function sendEmail(to: string, subject: string, html: string) {
  if (!process.env.RESEND_API_KEY) return
  try {
    await resend.emails.send({
      from: 'onboarding@resend.dev',
      to,
      subject,
      html,
    })
  } catch (err) {
    console.error('Email send error:', err)
  }
}
```

### STEP 3 — Send email when ticket request_status is approved or refused

**File:** `server/routes/tickets.ts` — inside the `router.patch('/:id', ...)` handler, after `request_status` is updated.

Add:
```ts
if (request_status && ticket?.user_id) {
  const [requester] = await db.select().from(profiles).where(eq(profiles.id, ticket.user_id))
  if (requester?.email) {
    const isApproved = request_status === 'approved'
    await sendEmail(
      requester.email,
      isApproved ? `✅ تمت الموافقة على تذكرتك` : `❌ تم رفض تذكرتك`,
      `<p>مرحباً ${requester.full_name || ''},</p>
       <p>${isApproved ? 'تمت الموافقة على تذكرتك' : 'تم رفض تذكرتك'}: <strong>${ticket.title}</strong></p>`
    )
  }
}
```

### IMPORTANT NOTES
- All `sendEmail` calls must use `await` and be wrapped in try/catch or rely on the existing try/catch in each route.
- Do NOT block the API response waiting for email — emails should be sent after `res.json(...)` or use `.catch(() => {})` if non-critical, similar to how `sendWhatsAppToUser` is already used in `attendance.ts`.
- Add `RESEND_API_KEY=` to the `.env` file (leave value empty — I will add my key manually).
- Do NOT change the schema, frontend files, or any other routes.
